# Einlang documentation

Use this page as the main documentation index. The main [README](https://github.com/einlang/einlang/blob/main/README.md) owns install and run instructions, [reference.md](https://github.com/einlang/einlang/blob/main/docs/reference.md) owns language semantics, and [stdlib.md](https://github.com/einlang/einlang/blob/main/docs/stdlib.md) owns built-in modules and functions.

---

## Need help?

- **New to Einlang?** Start with [GETTING_STARTED](https://github.com/einlang/einlang/blob/main/docs/GETTING_STARTED.md), then use [README — Try it](https://github.com/einlang/einlang/blob/main/README.md#try-it) and the [examples learning path](https://github.com/einlang/einlang/blob/main/examples/README.md#learning-path).
- **Prefer to learn by doing?** Go to [examples/README](https://github.com/einlang/einlang/blob/main/examples/README.md) and pick a domain or the linear learning path.
- **Prefer to learn by reading?** Go to [reference](https://github.com/einlang/einlang/blob/main/docs/reference.md), [stdlib](https://github.com/einlang/einlang/blob/main/docs/stdlib.md), and [AUTODIFF](https://github.com/einlang/einlang/blob/main/docs/AUTODIFF.md).
- **Coming from another background?** Use [SYNTAX_COMPARISON](https://github.com/einlang/einlang/blob/main/docs/SYNTAX_COMPARISON.md) or [EINLANG_FOR_JULIA_PROGRAMMERS](https://github.com/einlang/einlang/blob/main/docs/EINLANG_FOR_JULIA_PROGRAMMERS.md).
- **Need to ask a question or contribute?** See [CONTRIBUTING](https://github.com/einlang/einlang/blob/main/CONTRIBUTING.md) and [GitHub issues](https://github.com/einlang/einlang/issues).

## Quick answers

| Question | Answer |
|----------|--------|
| **How do I run Einlang?** | `python3 -m einlang -c "let x = 1+1; print(x);"` or `python3 -m einlang examples/hello.ein` |
| **How do I use it from Python?** | `from einlang import run` — see [README — Install & run](https://github.com/einlang/einlang/blob/main/README.md#install--run) |
| **Where are the examples?** | [examples/README](https://github.com/einlang/einlang/blob/main/examples/README.md) |
| **How do I get derivatives?** | Bind the value first, then use `@name`, `@a / @b`, `@loss / @w`, or `@C / @A`; see [AUTODIFF](https://github.com/einlang/einlang/blob/main/docs/AUTODIFF.md) |
| **Where do I start if I know Julia or Python?** | [EINLANG_FOR_JULIA_PROGRAMMERS](https://github.com/einlang/einlang/blob/main/docs/EINLANG_FOR_JULIA_PROGRAMMERS.md) or [SYNTAX_COMPARISON](https://github.com/einlang/einlang/blob/main/docs/SYNTAX_COMPARISON.md) |
| **How do I report a bug?** | Open an [issue](https://github.com/einlang/einlang/issues) or see [CONTRIBUTING](https://github.com/einlang/einlang/blob/main/CONTRIBUTING.md) |

## Design summary

Short version:

- keep tensor structure explicit in the source
- catch shape and index errors before execution
- keep differentiation in the language
- use one language for model code, optimization, and numerical programs

For the user-facing motivation page, see [WHY_EINLANG](https://github.com/einlang/einlang/blob/main/docs/WHY_EINLANG.md). For doc-set rules and single-source-of-truth decisions, see [DOCUMENTATION_DESIGN](https://github.com/einlang/einlang/blob/main/docs/DOCUMENTATION_DESIGN.md).
