# Manuscript Targets

This page records the editorial bar for the book manuscript.

Each numbered chapter should be at least 5,000 words before the book is treated
as complete. The current chapter files are intentionally structured as chapters,
but they still need substantial expansion before they meet that bar.

## Expansion Standard

Expansion should not be filler. Each chapter should grow by adding:

- a stronger chapter opening that motivates the abstraction;
- a worked program that is read in several passes;
- a semantic model for the chapter's main construct;
- a compiler-facing interpretation of the same construct;
- at least one realistic example drawn from Einlang's current implementation or
  examples;
- a bridge to the following chapter.

The book should stay tutorial-first and avoid exercise/problem-set sections.
